# 🌤️ Weather Dashboard

Aplicação web para consulta de clima em tempo real, com interface moderna e responsiva.

## 🚀 Tecnologias
- React
- TypeScript
- Tailwind CSS
- Vite
- OpenWeather API

## ✨ Funcionalidades
- Busca por cidade
- Exibição de temperatura e condições
- Loading skeleton
- Tratamento de erros
