# 🌤️ Weather Dashboard

Um dashboard de clima moderno e interativo desenvolvido com React, TypeScript e TailwindCSS.

O projeto permite buscar o clima de qualquer cidade, salvar favoritos e obter automaticamente o clima da sua localização atual.

---

## 🚀 Funcionalidades

* 🔍 Busca de clima por cidade
* ⭐ Salvamento de cidades favoritas (persistência com LocalStorage)
* 📍 Geolocalização (clima da sua localização atual)
* ⏳ Loading states com feedback visual
* ⚠️ Tratamento de erros (API e permissões)
* 🎨 Interface moderna com TailwindCSS
* ✨ Micro-interações e animações (hover, loading, transições)

---

## 🧠 Tecnologias utilizadas

* React
* TypeScript
* Vite
* TailwindCSS

## ⚙️ Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/PedroMacuje/Weather-Dashboard.git

# Entre na pasta
cd Weather-Dashboard

# Instale as dependências
npm install

# Rode o projeto
npm run dev
```

---

## 🔑 Configuração da API

Este projeto utiliza a API do OpenWeather.

1. Crie uma conta em: https://openweathermap.org/api
2. Gere sua API Key
3. Adicione no arquivo:

```ts
const API_KEY = "SUA_API_KEY"
```
